The FormulaRenderRuntime.js file is a minified bundle of the MathJax source
and PicShot's FormulaRender-entry.js adapter. The source is not otherwise
patched. Only the base and AMS TeX configurations and SVG TeX glyph paths
are included. The font outline source files identify their license as
Apache-2.0, e.g. ts/output/svg/fonts/tex/normal.ts at the pinned revision.

PicShot adapter changes: local-only request validation, restricted packages,
500 macro substitutions, bounded TeX buffers, strict outline extraction,
self-contained SVG serialization and semantic MathML serialization.
The build-time esbuild 0.25.12 tool is MIT-licensed, is not included in the
runtime bundle and is not distributed as an executable in the app.
Node, npm, a browser runtime and the npm dependency tree are not shipped.
